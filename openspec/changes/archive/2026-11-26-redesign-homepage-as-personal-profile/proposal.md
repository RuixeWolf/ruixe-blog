# Proposal

## Why

Ruixe Blog 的首页目前复用完整文章列表，关于页也只有简短的作者介绍。分享首页链接时，访客应能先认识 Ruixe，随后直接阅读文章、前往 GitHub 或发起合作联系。

## What Changes

- 用 Ruixe 的狼设定插画作为首页横幅背景，小头像与名字同行。桌面端文字居左、角色居右，窄屏先展示插画，再展示个人介绍。以「浏览文章」为主操作，并提供关于我、GitHub 个人主页和合作邮箱入口。
- 个人介绍下方展示手选文章，顺序来自站点 YAML，标题和摘要随语言切换。完整文章索引保留在语言对应的文章页，桌面主导航和移动抽屉均提供入口。
- 扩充双语关于页的作者介绍和建站缘由，并把现有博客配图、建站记录和许可信息放在关于博客部分。
- 将公开邮箱 `RuixeWolf@outlook.com` 纳入站点配置。访客可直接读取或点击邮箱地址，展示文本与邮件链接由同一配置值生成。

### New Capabilities

### Modified Capabilities

- `app-layout`：定义首页名片与内页布局，扩展桌面及移动主导航，并复用现有 GitHub 头像来源。
- `mdx-content`：明确首页与文章列表页的职责，调整文章列表验收入口并扩充双语关于页。
- `i18n-routing`：更新中英文首页及内部入口的场景，并按现有根路由参数机制描述静态预渲染。
- `site-config`：增加公开显示名、合作邮箱及有序精选文章 slug 列表，并校验配置。

## Impact

- 主要涉及 locale 根布局、首页及关于页、文章相关页面的内容布局、共享导航、中英文文案、站点 YAML 和服务端配置加载器。
- 实施应维持现有公开 URL、文章的分享图与 Markdown 端点、语言切换和本地化 404。继续使用现有 GitHub 用户信息接口、站点分享图和发布流程。
